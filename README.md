# AWS Cloud Portfolio

My personal cloud portfolio website built to showcase my projects, skills, and experience with AWS and cloud computing.

I built this project to get hands-on experience with AWS services and learn how different cloud services work together.

## Live Website

[Visit my portfolio](https://hunterulrich.dev/)

## Features

* Personal portfolio and resume
* Cloud and software engineering projects
* Visitor counter
* Simple chatbot
* Custom domain
* HTTPS
* CloudFront content delivery

## AWS Services

This project uses several AWS services:

| Service                | Purpose                             |
| ---------------------- | ----------------------------------- |
| **Amazon S3**          | Hosts the static website            |
| **Amazon CloudFront**  | Provides content delivery and HTTPS |
| **AWS Lambda**         | Runs serverless backend functions   |
| **Amazon API Gateway** | Handles API requests                |
| **Amazon DynamoDB**    | Stores application data             |
| **Amazon SNS**         | Handles notifications               |
| **Terraform**          | Manages AWS infrastructure as code  |

Cloudflare is also used for DNS and the custom domain.
